# Iconos LegalMEV

Iconos de la extensión Chrome, generados a partir de `icon-base.png`.

## Fondo transparente

Para iconos con **fondo transparente**, colocá `icon-base.png` en esta carpeta con canal alpha y ejecutá:

```bash
npm run generate-icons
```

El script regenera los tamaños: 16, 32, 48 y 128 px.
